# ByeoRim — 02C refined

외곽은 한글 `ㅂ`, 하나로 연결된 내부 구멍은 `ㄹ`이다. 퍼블리셔와 SNS 계정에서 같은 심볼을 사용한다.

## 파일

- `mark.svg` / `mark.png`: 벽돌색 심볼, 투명 배경. SVG가 기본 원본이다.
- `mark-ink.svg` / `mark-ink.png`: 먹색 단색 심볼, 투명 배경.
- `mark-white.svg` / `mark-white.png`: 밝은 심볼, 투명 배경.
- `profile-light.*` / `profile-dark.*`: 벽돌색과 밝은 바탕을 교차 적용한 1024×1024 정사각형 SNS 프로필. 플랫폼에서 원형으로 잘라도 심볼은 유지된다.
- `favicon.svg` / `favicon-16.png` / `favicon-32.png` / `favicon-48.png`: 작은 크기에 맞춰 여백을 줄인 파비콘. 밝은 배경 포함.
- `preview.png`: 같은 SVG 경로로 만든 원형·사각형 및 축소 미리보기.

## 조형 기준

- 외곽과 내부의 사선은 45°.
- ㅂ 상단의 두 획은 초기 정리안보다 48만큼 위로 연장해 축소했을 때도 초성 실루엣이 드러나도록 했다.
- 외곽 모서리 반경은 기본 16, 오른쪽 아래 사선의 양 끝은 시각적 부드러움을 맞추기 위해 40, 내부 모서리는 12 (1024 좌표계).
- 내부 ㄹ은 하나의 연속된 구멍이며, SVG의 `fill-rule="evenodd"`로 표현한다.
- 확정 기본색: 벽돌색 Oxide `#A44636` (RGB 164, 70, 54).
- 보조색: 먹색 `#1B1B1A`, 밝은색 `#FBFBFA`, 연한 벽돌색 바탕 `#FAF1EC`.
- SNS 프로필은 원본 좌표계에서 88% 축소해 원형 크롭용 여백을 확보한다.

## 재생성

Node.js와 `sharp`가 필요하다. `node brand/byeorim/build.mjs`를 실행한다. 별도 설치 위치를 사용할 때는 `SHARP_MODULE`에 sharp 패키지 경로를 지정한다. 모든 출력은 같은 경로에서 파생되므로 프로필 모양을 따로 다시 그리지 않는다.

이번 작업은 브랜드 파일 제작이며 웹사이트나 SNS 계정에 자동 적용하지 않는다.
